# Формат fcrypt, версия 1

Все многобайтовые целые числа записаны в big-endian. Формат фиксирован для
версии 1; неизвестные версии, алгоритмы и параметры отклоняются.

## Заголовок (80 байт)

| Смещение | Размер | Поле |
|---:|---:|---|
| 0 | 8 | магия `FCRYPT01` |
| 8 | 2 | ID шифра: `1` = ChaCha20-Poly1305 |
| 10 | 2 | ID KDF: `1` = Argon2id |
| 12 | 4 | версия Argon2: `0x00000013` (v19) |
| 16 | 4 | memory cost, КиБ |
| 20 | 4 | time cost (итерации) |
| 24 | 4 | lanes |
| 28 | 4 | размер блока открытого текста, байт |
| 32 | 8 | точный размер исходного файла, байт |
| 40 | 32 | соль Argon2id |
| 72 | 8 | префикс nonce |

Допустимые значения в версии 1:

- memory cost: 8192..1048576 КиБ;
- time cost: 1..16;
- lanes: 1..16;
- memory cost >= 8 × lanes;
- размер блока: 65536..16777216 байт (по умолчанию 1048576);
- число блоков: 1..2^32−1 (один блок минимум даже для пустого файла).

Заголовок хранится открыто. Его целостность проверяется тегом каждого блока:
заголовок целиком входит в AAD. Изменение любого поля приводит к ошибке
аутентификации (кроме изменений, которые сначала отвергаются как
недопустимые параметры).

## Вывод ключа

32-байтовый ключ:

```text
key = Argon2id(
    password  = пароль,
    salt      = 32-байтовая соль из заголовка,
    version   = 0x13,
    m_cost    = memory cost (КиБ),
    t_cost    = time cost,
    p         = lanes,
    out_len   = 32,
    AD        = "fcrypt/v1/argon2id/file-key"
)
```

Параметр `threads` влияет только на производительность, не на результат.
При скрытом вводе на Windows пароль вводится в Unicode и кодируется в UTF-8;
на Unix используются байты, введённые в терминал. В режиме
`--password-stdin` используются ровно те байты, которые переданы в stdin.

## Блоки

`chunk_count = 1`, если размер файла равен 0, иначе
`chunk_count = ceil(plaintext_size / chunk_size)`.

Для блока с номером `i` (от 0):

```text
nonce = nonce_prefix (8 байт) || uint32_be(i)

AAD = header (80 байт)
    || uint64_be(i)
    || final_flag (1 байт: 1 для последнего блока, иначе 0)
    || uint32_be(plaintext_length)

ciphertext || tag = ChaCha20-Poly1305(
    key, nonce, AAD, plaintext_chunk
)
```

`final_flag` и длина блока вычисляются из аутентифицированного размера файла.
Номер блока и флаг не дают переставлять, дублировать или обрезать блоки.
Точный ожидаемый размер зашифрованного файла:

```text
80 + plaintext_size + chunk_count × 16
```

Файл ровно такого размера требуется при расшифровке. Любой лишний или
недостающий байт — ошибка.

## Раскладка файла

```text
+----------------------+ 0
| header (80)          |
+----------------------+ 80
| ciphertext chunk 0   |
| tag chunk 0 (16)     |
+----------------------+
| ciphertext chunk 1   |
| tag chunk 1 (16)     |
+----------------------+
| ...                  |
+----------------------+
| ciphertext chunk N-1 |
| tag chunk N-1 (16)   |
+----------------------+
```

Для пустого файла существует один блок длины 0, состоящий только из 16-байтового
тега. Поэтому минимальный зашифрованный файл — 96 байт.

## Что не входит в формат

- имя и путь исходного файла;
- временные метки, владелец, права доступа;
- пароль, его хеш или проверочное значение;
- случайное заполнение (padding) — точный размер исходного файла виден.

Расширение `.fcrypt` — соглашение об именовании, а не часть формата.
